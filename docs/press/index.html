A button that goes down fast and comes back with a little spring. Try the mouse, a finger, or the space bar.

Fast down, slow up

Pressing takes 60ms so it feels instant. Releasing takes 320ms with an overshoot curve, which reads as a spring.

Only the face moves

The darker base never moves. The face drops into it, so the button looks pressed without shadows changing.

Same feel everywhere

Pointer, touch and keyboard all set the same pressed state. Dragging off the button cancels the press, like a native button.
